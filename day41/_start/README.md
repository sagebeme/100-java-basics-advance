# Day 41 - Starter

`src/index.html` is the skeleton of the kibanda's page, with a `<!-- TODO -->` in every section, and `src/style.css` has the colours named for you. `src/PageCheck.java` is a finished tool that checks your page for common mistakes:

```bash
cd day41/_start/src
javac -cp "../../../lib/*" PageCheck.java
java -cp ".:../../../lib/*" PageCheck index.html
```

Open `index.html` in your browser as you go: double-click it, or drag it into a browser window, and refresh after each change. Follow **Steps** in the day's [README](../README.md#-steps).
